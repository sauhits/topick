# 二者対話を対象とした話題分析
## はじめに
実生活にて，他者との対話の機会は当事者間はもちろん，多様な感情・情報の共有という観点より重要である．
これはLLMとの対話においても同様である．また，対人間との会話は対LLMとの会話よりも一般的に情報の展開が早く，自然である．
当実装では，二者対話の発話ログを用いて話題の抽出と話題遷移の検知を目指した．

## 手法
二者対話データを用いてBERTモデルを訓練し，発話毎にスライドウィンドウを作成し，話題語の抽出を行う．
ストップワードも二者対話データの発話を用いて作成した．
次にBERTのattention層から話題語のベクトル成分を取得し，ウィンドウ毎に比較した．
比較はコサイン類似度を用いて行い，閾値を超えた話題語については話題遷移が発生したと判定した．
また，話題遷移は徐々に行われることが多いため，一定数前のウィンドウの話題語とも比較するようにした．

二者対話データは名大発話コーパス及びRealPersonaChatを用いた． \
利用したモデルは'cl-tohoku/bert-base-japanese-whole-word-masking'である．

## 考察
おおむね発話の特徴を捉え，話題遷移を検出できていると考えられる．
日本語のリアクションはオノマトペという文化上，多様化しているため独立した検出は困難である．
対話用にfine-tuneしたモデルを用意するとさらに精度が上昇する可能性がある．

## 展望
リアクションの多様性・揺らぎを除去するために，リアクションが日本語よりも少ない言語へ翻訳することで一定量の正規化が考えられる．
しかし，固有の表現が失われる可能性が高い．

追加研究として，ベクトル化した発話には発話者の思考や性格が乗っている可能性があるため，これらを用いた任意の発話者らしい発話の作成を試みる．
